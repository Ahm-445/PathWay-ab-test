# PathWay
# تذكير السلة المتروكة: تجربة A/B

## الوصف
متجر إلكتروني (تطبيق وموقع) يدرس إرسال تذكير للمستخدم الذي ترك سلته دون شراء. تساعد التجربة على قرار واحد: نطلق التذكير لكل المستخدمين أو لا نطلقه.

## السؤال والفرضية
- القرار: نطلق رسالة تذكير السلة المتروكة لكل المستخدمين أو لا نطلقها.
- الفرضية: إذا أرسلنا تذكيرًا بعد 3 ساعات من ترك السلة فستزيد نسبة إتمام الشراء، لأن جزءًا من ترك السلة سببه النسيان أو الانشغال.

## التصميم
- وحدة العشوأة: المستخدم (user_id)، بتوزيع ثابت بالـ hash، و50% لكل نسخة.
- المقياس الرئيسي ومقاييس الحماية: الرئيسي نسبة من طلبوا. والحماية: الربح لكل مستخدم، ونسبة إلغاء الطلبات، والتواصل مع الدعم.
- حجم العينة والمدة: 12,206 مستخدمين في كل مجموعة، و14 يومًا (أسبوعان كاملان)، بنسبة أساسية 8% وأصغر أثر يهمنا نقطة واحدة.

## النتائج والتوصية
- الأثر الرئيسي وفترة الثقة: +1.22 نقطة مع CUPED (فترة الثقة 95% من 0.64 إلى 1.80)، من 8.16% إلى 9.38%.
- التوصية: لا نطلق الآن. التذكير رفع الطلبات والربح، لكن التواصل مع الدعم ارتفع 0.70 نقطة (من 0.32 إلى 1.08). نعالج سبب ذلك ثم نعيد التحقق.
